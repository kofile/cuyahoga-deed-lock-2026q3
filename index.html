What this is. Cuyahoga citizens enroll a parcel ID at the recorder's counter. Any transfer document submitted against that parcel locks the order at recorder intake and triggers a single SMS — branded as Cuyahoga County, not Neumo — to the citizen with a one-time code. The citizen replies CONFIRM or DISPUTE. The order doesn't move until the citizen acts or a supervisor manually resolves it. Claims are valid 12 months and require renewal (renewal flow is Phase 2).
Architectural reframe — April 29 review
The upfront enrollment is NOT Deed-Lock-specific. We are building a generalized Enrollment Framework that will support multiple programs: Deed Lock (Cuyahoga, Q2), Protected Individuals (Summit County), Safe at Home, and others. Deed Lock is the first program riding on the framework.

The citizen's journey

A property owner walks into the recorder's office to enroll, then later receives an SMS the moment any transfer document is filed against their parcel.

01
Citizen → Counter

Walk in to enroll

Visits the Cuyahoga recorder's office in person with government-issued ID and proof of ownership.

  • Counter-only — no online enrollment in Phase 1
  • Individual ownership only — LLC / commercial property excluded
  • Cuyahoga owns identity verification — Neumo doesn't validate ID
  • Claim is valid for 12 months — citizen must renew to maintain protection
02
Citizen → Clerk

Verify mobile via Platform's React component

Clerk enters the citizen's mobile into the enrollment screen. The Platform's pre-built React component sends a verification OTP — citizen reads it aloud, clerk types it back to confirm.

  • AWS requires this verification before any future SMS can send to that number — not optional
  • Becomes the 2FA channel for all future transfer alerts on this parcel
03
System → Citizen

Enrollment confirmation SMS — Cuyahoga branded

On activation, the citizen receives a confirmation SMS naming their property and the 12-month claim window.

SMSCuyahoga County
Cuyahoga County: Your property at 1247 Elm Ave (Parcel 542-19-008) is now enrolled in Deed Lock protection. Valid for 12 months. Reply STOP at any time to unsubscribe.
Today · 10:42 AM
Branding (May 6): SMS sender ID is Cuyahoga County, NOT Neumo. Confirmed by Brian — citizens must recognize the source as their county.
04
System → Citizen (later)

Transfer alert lands

Weeks or months later, a transfer document is submitted against this parcel. Within seconds the citizen receives a single SMS — address, parcel ID, embedded OTP.

SMSCuyahoga County
Cuyahoga County Deed Lock: A transfer document was submitted for 1247 Elm Ave (Parcel 542-19-008). Reply CONFIRM 482917 to authorize or DISPUTE 482917 to flag as fraud. Expires in 24 hrs.
Today · 2:13 PM
  • Single SMS — within 160 GSM characters (one segment)
  • Order is held in suspended state until reply or 24-hr timeout
05
Citizen → System

Reply: CONFIRM or DISPUTE — last reply wins, max 3 attempts

Citizen replies CONFIRM 482917 to authorize or DISPUTE 482917 to flag fraud. Per May 6 Cuyahoga confirmation: citizen can change their mind up to 3 total attempts — the last valid reply within the limit is the winner.

SMSCuyahoga County
Cuyahoga County Deed Lock: A transfer document was submitted for 1247 Elm Ave...
DISPUTE 482917
2:14 PM
Received. This transfer has been flagged for review by a Cuyahoga County supervisor.
  • CONFIRM + valid code → order unlocks; clerk notified; recording proceeds
  • DISPUTE + valid code → order escalated to supervisor with fraud flag
  • 3 attempts exceeded → order force-locked; routed to supervisor regardless of intent
  • Invalid code → ignored; original OTP remains active
06
Edge cases

What if the citizen doesn't reply?

  • 12 hours of silence → reminder SMS with the same OTP
  • 24 hours of silence → escalates to supervisor with "Citizen non-responsive" flag; order remains held
07
Edge cases

What if the citizen has STOP'd from SMS?

Decision (May 6, Brian): If a citizen has STOP'd from SMS and a transfer document later hits their parcel, they have effectively self-removed from the program. Cuyahoga will document this as the citizen's responsibility in their county-side procedures. The order processes normally — no Neumo system intervention required.

This simplifies Phase 1 substantially. Brian explicitly took ownership of writing this rule into Cuyahoga's user-facing program documentation.

08
Phase 2 preview

Renewal

Phase 1 does not include automated renewal reminders or self-service renewal. Phase 2 will add:

  • Email reminder approximately 2 weeks before claim expires
  • One-click renewal (no re-enrollment needed since nothing has changed — same owner, same property, same mobile)

We have a 12-month runway from Phase 1 launch to deliver Phase 2 renewal — the first claim doesn't expire until then.

System architecture & technical specs

Four-component split: Spider holds the program registry, Cloud Records owns the enrollment framework + Deed Lock business logic, Platform owns SMS infrastructure, Supervisor queue handles human-in-the-loop. All OTP parsing logic lives in Records — Platform never inspects message content.

Architectural foundation

Enrollment Framework — built once, hosts many programs

The same upfront construct is needed for Deed Lock, Protected Individuals (Summit County), Safe at Home, and other future programs. Building it once means future programs are configuration + program-specific rules, not new builds.

Two parts:

  • Spider — Program Registry. Holds the source list of available programs and which tenants are enabled for which. Per Andy: Q2 path; Q3+ has a different config approach coming.
  • Cloud Records — Citizen Enrollment & Program Association. UI for clerks to register a citizen, capture mobile (verified via Platform React component), associate to one or more enabled programs.

Data the framework owns (program-agnostic):

  • Citizen identity (name, no DLN, audit fields)
  • Verified mobile number (AWS opt-in handshake completed)
  • Program associations (one citizen → many programs)
  • Enrollment date + expiry date per association
  • Registering clerk audit trail

Growth opportunity · Sourced from May 6 (Brian + Dave Weaver)

Brian explicitly positioned Deed Lock as a productized subscription service ("$50/year per parcel, county keeps some, you keep some, link it to any parcel database") and noted that recorders in Ohio lack legal authority to reject transfers — that authority sits with auditor offices. This makes auditor offices the strategic expansion target for Deed Lock.

Brian is fielding inbound from Arizona and Tennessee on deed-fraud prevention; he reports these states have nothing equivalent in place. Dave Weaver volunteered to leverage his wife's auditor connections to drive adoption. Cuyahoga is positioned to be a national reference customer.

Implications:
